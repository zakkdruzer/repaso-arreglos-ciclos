# Repaso: Arreglos y Ciclos

Proyecto de práctica con JavaScript para reforzar arreglos, ciclos, matrices y métodos como `map`, `filter`, `reduce`, `sort`, además de estructuras como `while` y `do...while`.  
El ejercicio integra una interfaz visual con **Bootstrap 5** y un estilo tipo arcade para indicar que los resultados se ven en la consola del navegador.

## Descripción
Este proyecto reúne 10 retos de JavaScript organizados en archivos separados.  
Cada reto trabaja un concepto distinto y el archivo `liga-final.js` funciona como el reto integrador final.

## Objetivo
Practicar y repasar:
- Creación y manipulación de arreglos.
- Uso de `push`, `includes`, `length`.
- Transformación y filtrado con `map` y `filter`.
- Acumulación con `reduce` y acumuladores manuales.
- Ordenamiento con `sort`.
- Recorrido con `for`, `for` anidado, `while` y `do...while`.
- Trabajo con matrices.
- Resolución de un ejercicio integrador final.

## Tecnologías utilizadas
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Interfaz
El archivo `index.html` incluye una interfaz visual con Bootstrap y estilos personalizados:
- Fondo con degradado oscuro.
- Un contenedor central estilo arcade.
- Un aviso llamativo para indicar que los resultados se ven en la consola.
- Carga de cada archivo con `type="module"` para evitar conflictos entre variables de los distintos retos.

## Estructura del proyecto
- `index.html`: página principal con la interfaz visual.
- `reto-1.js`: el cajón de frutas.
- `reto-2.js`: transformar y filtrar.
- `reto-3.js`: las cuentas del mes.
- `reto-4.js`: ordenar de menor a mayor.
- `reto-5.js`: pasar lista.
- `reto-6.js`: recorrer una matriz.
- `reto-7.js`: buscar en el mapa.
- `reto-8.js`: la pelota que rebota.
- `reto-9.js`: la contraseña.
- `liga-final.js`: el gran reto integrador.

## Cómo ejecutar el proyecto
1. Abre `index.html` en tu navegador.
2. Presiona `F12` o abre las herramientas de desarrollador.
3. Ve a la pestaña **Console**.
4. Revisa los resultados de cada reto.

## Aprendizajes
Con este ejercicio se refuerza:
- La lógica básica de programación.
- El uso de arreglos y matrices.
- El trabajo con ciclos anidados.
- La manipulación de datos numéricos y textuales.
- La construcción de soluciones paso a paso.

## Ejemplo de salida
Los retos imprimen resultados como:
- Totales de arreglos.
- Promedios.
- Ordenamientos.
- Búsquedas en matrices.
- Validación de intentos.
- Rango de premios y fondo restante.

## Notas
- Cada archivo usa `type="module"` para que sus variables no choquen entre sí.
- El proyecto está diseñado para observarse principalmente en la consola del navegador.
- Bootstrap se usa solo para embellecer la pantalla inicial, no para mostrar los resultados de los retos.
