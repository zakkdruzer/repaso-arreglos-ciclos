# Reto 10 · La Liga de Equipos · Jefe Final

## Descripción
Este ejercicio integrador reúne varios conceptos de JavaScript vistos en la lección, como arreglos, matrices, ciclos `for`, `for` anidado, `while`, `filter`, `sort` y acumuladores.  
A partir de una lista de equipos y sus puntos por ronda, el programa calcula totales, promedio general, ranking y campeón, además de simular la entrega de premios.

## Objetivo
Practicar la resolución de problemas usando:
- Arreglos.
- Matrices.
- Ciclos `for` y `for` anidado.
- Acumuladores.
- Métodos `filter()` y `sort()`.
- Estructura `while`.

## Funcionalidades
- Muestra cuántos equipos compiten.
- Calcula el total de puntos de cada equipo.
- Guarda los totales en un arreglo.
- Calcula el promedio general.
- Filtra los totales que superan el promedio.
- Ordena los totales de mayor a menor.
- Identifica al campeón.
- Reparte premios mientras exista fondo suficiente.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript

## Estructura del proyecto
- `index.html`: página principal.
- `reto-1.js` a `reto-9.js`: ejercicios previos.
- `liga-final.js`: ejercicio integrador o jefe final.

## Cómo ejecutar el proyecto
1. Abre el archivo `index.html` en tu navegador.
2. Revisa la consola del navegador.
3. Observa la salida de cada reto.

## Aprendizajes
Con este ejercicio se refuerza:
- El recorrido de matrices.
- El uso de acumuladores.
- El trabajo con arreglos derivados.
- La ordenación de datos numéricos.
- El control de repeticiones con `while`.

## Resultado esperado
El ejercicio muestra:
- La cantidad de equipos.
- El total de puntos por equipo.
- El promedio general.
- Los equipos sobre el promedio.
- El ranking de puntajes.
- El nombre del campeón.
- La entrega de premios desde un fondo limitado.
